# Artist Discography App

This directory contains the Next.js application source code for **Artist Discography**.

For full project documentation, key features, technology stack, and repository overview, please refer to the main [Root README](../README.md).

## Quick Start

Run the development server from this directory:

```bash
bun dev
```

Or from the repository root:

```bash
cd artist-discography
bun dev
```
